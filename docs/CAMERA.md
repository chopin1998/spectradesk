# 摄像头光谱仪

## 设备和采集

默认工作台有 FLA5000、摄像头光谱仪、叠加、上下显示四个标签。左侧只显示已检测到的设备块；对应设备标签也随检测结果显示或隐藏，仅两台都检测到时显示叠加和上下显示。未检测到任何设备时显示灰色连接提示并清空右侧设备页，插拔后自动更新。首次检测到设备时自动连接，但不自动开始采集。设备仍插着时，主动断开会保留对应块且不自动重连；拔出再插入后重新自动连接。连接失败不循环重试，可手动再连接。两台设备各自连接、采集、停止和调参，切换标签不会停止采集。两台是并行采集，不是硬件同步触发。设备若被 VirtualBox 占用，先释放 USB。

当前相机适配在 Linux V4L2 下使用 MJPG 1920×1080，设备路径优先选 `/dev/v4l/by-id/`。内置档案针对 2025051804 这台卖家设备，不适用于任意摄像头光谱仪。

每次连接摄像头后关闭自动白平衡，并固定为4600 K；色温保存在相机校准档案的 `white_balance_temperature` 中，旧档案也默认4600 K。校准预览和正常采集共用这套连接设置。程序核对设备读回值并丢弃切换期间的8帧；设备不支持或设置未生效时明确报错。测量文件的设备信息记录实际白平衡参数。固定白平衡仍是相机处理后的RGB，不等于绕过通道增益或完成光谱响应标定。

曝光框直接显示毫秒。该设备控制接口报告范围7.8–1000 ms、步进0.1 ms，但实际输出存在曝光台阶。程序按协商帧率的帧间隔进一步限制设定上限：当前1920×1080 MJPG协商为30 fps，上限33.3 ms。写入后读回确认不等于真实受光时间验证。实测8.3→8.4 ms有明显亮度跳变，关闭防闪烁后仍存在；31.2、100、1000 ms的弱峰输出几乎相同，不能把读回的长曝光当成真实可用范围。设备块同时显示曝光设定和未归一化峰值 DN。

“光谱自动曝光”由软件按取样条带 RGB 最大值测光，目标区间约170–220 DN。偏暗时增加曝光，偏亮时缩短，达到250 DN时下一组减半。每次调整最多两倍，平均组内曝光固定。硬件整幅画面的自动曝光保持关闭，避免大面积黑色背景诱发过曝。最短7.8 ms仍饱和时需要减弱入光。关闭自动后，采集不会再运行防饱和调节。

平均帧数范围1–8，平滑范围0–8（0关闭）。FLA5000自动积分完成后会结合最终参数下实测单帧耗时调整平均：当前输出低于1 Hz改为1帧，高于约20 Hz适当增加，最多8帧。取消自动积分保留原平均设置。

## 图像提取和预览

相机采样为 `0.299R + 0.587G + 0.114B`，再对条带逐列平均，单位为解码后灰度 DN。分析使用未平滑校正数据，显示平滑不改变分析；未复现 Theremino 的时间滤波和双向空间滤波。

Windows Theremino 3.1 的 DirectShow 回调直接包装 bottom-up RGB24 内存，OpenCV输出是top-down。卖家 `StartY=50 / SizeY=4` 在1080行图像中实际对应 Linux 第540–582行（零基），纵向参数单位为百分比。已用同帧经过原版回调与提取函数验证；v5源码的纵向单位不同，不能混用。

摄像头单独页右上角“显示原始光带”可开关预览。仅显示取样条带，并按当前波长映射横向插值，与主图位置和游标对应。插值只影响预览，保存的图像仍是原始解码BGR帧。

## 波长校准

右上角“设备校准”集中放置两台的校准操作。摄像头页提供：

- **FLA5000参考标定**：两台采集同一光源后，使用打开窗口时的光谱快照。可点击相机峰与FLA5000对应峰配对，或加载FLA5000完整NPZ。
- **三原色灯自动找峰配对**：依靠已有大致波长映射，在可见光段建议配对并剔除明显不符的点。需要至少4对可靠且分布足够宽的峰；结果是草案，检查后再保存，不会自动覆盖校准。
- **手工标定**：编辑像素和已知波长。单点偏移保留原色散关系；线性至少2点，二次至少3点。钠双线不能分辨时不能当成两个独立点估计色散。

拟合残差不代表绝对波长精度，应保留未参与拟合的峰独立验证。参考设备误差、两台的分辨率和光谱响应也会影响比较。保存后写入用户档案，已连接相机会重连应用新映射。

摄像头的“应用波长校准”可切换回卖家映射，“使用二次波长校准”可与线性拟合比较；也可叠加校准前曲线，或打开校准前/后/FLA5000对照窗口。这些波长开关与FLA5000的强度校正不同。

内置档案为 `src/spectradesk/data/camera-2025051804.json`，目前采用同光源FLA5000五峰二次拟合，覆盖约404–629 nm；新采集对照中主要窄峰相差约0.1–0.7 nm，宽峰最大约1.86 nm。这是相对参考验证，不是绝对精度。档案的标定点范围外显示外推标记。

用户保存的 `camera-profile.json` 优先于内置档案，位置由Qt的AppConfigLocation决定，通常为 `~/.config/SpectraDesk/camera-profile.json`，并遵循 `XDG_CONFIG_HOME`。原卖家INI不改写。更换设备、分辨率或取样几何后需重新检查标定。

## 暗背景和强度

固定手动曝光、遮光采集后，在设备校准中记录暗背景；再次点击可清除。改变曝光会清除旧背景。光路、增益或白平衡改变后也应重新采集。

DN不是ADC读数、绝对功率或光谱响应校正后的强度。即使波长对齐，两台的相对峰高也可能不同；不能据此视为定量辐射测量。

## 对比和保存

各光谱页共用绘图控件，默认OpenGL，软件绘制可用 `--renderer raster`。支持单色、彩虹线和彩虹填充；默认GPU后端也支持荧光余辉。

滚轮每格缩放约6%，单事件最多按两格处理；波段跨度最小5 nm，最大为当前设定波段，平移也受边界限制。左键拖动平移，双击恢复设定范围。上下图横坐标双向同步，连续采集保持手动缩放；修改左侧显示范围会应用新范围。游标、峰点与波长标签共用交互组件。

叠加可选各自峰值归一化，或左counts/右DN双纵轴。只在叠加和上下标签显示“峰对齐”入口，选择对应峰后临时平移摄像头曲线；按钮显示偏移量，切换波长校准会清除偏移。叠加右上角“底部对齐”按当前波段最低值做显示扣底并对齐双轴零线，游标会标注显示扣底。

峰对齐、底部对齐均不改变原始数据、校准和保存结果。两台连接且均已有测量时，一次保存生成 `名称-fla5000` 和 `名称-camera` 两个文件。NPZ保存每帧灰度、最后一帧BGR原图、波长和校准/采集信息；CSV不保存图像。两台保存的是各自最新一帧，不保证硬件同步。

实现依据是用户提供的Theremino 3.1 EXE的IL检查及INI，采用独立Python实现，未嵌入EXE或复制第三方项目代码。已完成同帧提取、Linux实采和FLA5000参考对照；长期稳定性及其他设备仍需分别验证。

标签状态以文字颜色和圆点区分采集中、已连接可用、待连接、未找到、异常，颜色随主题变化。仅一台开始采集或两台采集中停止其中一台时，自动切到仍采集设备的单独页；两台同时采集保留当前视图。用户之后手动切页不会被每帧刷新抢回。
