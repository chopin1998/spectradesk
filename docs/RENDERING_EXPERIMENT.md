# OpenGL 与荧光余辉实验

起源分支：`experiment/gpu-rendering`，现已并入主线。对照基线：`836bb95`。默认使用 OpenGL，普通绘制可通过 `--renderer raster` 选择。

## 运行

```sh
./run.sh --renderer opengl          # 连接真实光谱仪，启动后待机
./run.sh --demo --renderer opengl   # 无硬件演示
./run.sh --renderer raster         # 普通绘制
./run.sh --renderer cached-image   # Qt 图像缓存对照
```

在左侧“显示”选择单色线、彩虹线、彩虹填充或荧光余辉。四种模式均可使用 OpenGL。

着色器根据实际上下文选择：桌面现代上下文使用 GLSL 1.40，OpenGL ES 使用 GLSL ES 1.00 语法，较旧桌面上下文生成 GLSL 1.20 语法。桌面 OpenGL 与强制创建的 ES 上下文均通过本机 GPU 像素测试；其他显卡和旧桌面上下文仍需验证。实现复用当前锁定版本 pyqtgraph 的顶点上传、变换和裁剪设施。不改变 USB 采集、完整光谱、分析算法和保存数据。

## 显卡具体做了什么

- 彩虹线：顶点着色器保留波长坐标，片段着色器按同一组波长色标插值。计算颜色时补回顶点上传前的坐标原点偏移。
- 彩虹填充：以光谱和零基线生成三角条带；片段着色器计算颜色，混合阶段保留原来的透明度。
- 荧光余辉：两张 RGBA 显卡纹理交替作为帧缓冲。新光谱到达时，将旧纹理乘以 `exp(-dt/0.55)`，再直接在显卡绘制光晕与亮线，最后回贴到图表。无须每帧在 CPU 生成余辉图片或读回显存。
- 余辉使用实际时间衰减。单纯重画同一帧不重复累计亮度；停止采集后保持最后画面。坐标范围、布局、大小和显示模式变化时清空旧历史，避免错位。
- Qt 自身的帧缓冲目标会被保存和恢复；纹理使用独立采样单元。图形资源随 OpenGL 上下文清理。

普通后端仍使用 CPU 图像计算荧光余辉，作为对照。GPU 和 CPU 的发光细节不要求逐像素一致：GPU 有多层亮线光晕，CPU 使用低分辨率历史图像加模糊。两者分析数据相同。

## 性能对比

2026-11-11，本机 RTX 2080 Ti，NVIDIA 610.57.04 / OpenGL 4.6，1180×760 窗口；2048 点、平滑 1、叠加原始曲线、浅色主题。

每项预热 12 帧、测量 50 帧，每帧改变数据并上传。两种后端均强制重画；OpenGL 每帧 `glFinish` 等待完成。关闭 swap interval，因此这里不是正常垂直同步下的显示帧率。以下是同条件的一次对比，单位 ms/帧：

| 场景 | 显示 | 普通 CPU 时间 | OpenGL CPU 时间 | 普通实际耗时 | OpenGL 实际耗时 |
| --- | --- | ---: | ---: | ---: | ---: |
| 主峰 | 单色 | 5.89 | 2.20 | 4.58 | 2.22 |
| 主峰 | 彩虹线 | 5.85 | 2.17 | 4.55 | 2.18 |
| 主峰 | 彩虹填充 | 6.42 | 2.18 | 5.09 | 2.19 |
| 主峰 | 荧光余辉 | 6.99 | 2.32 | 5.49 | 2.34 |
| 暗场噪声 | 单色 | 6.19 | 1.62 | 4.43 | 1.63 |
| 暗场噪声 | 彩虹线 | 6.39 | 1.62 | 4.67 | 1.63 |
| 暗场噪声 | 彩虹填充 | 7.13 | 1.63 | 5.40 | 1.65 |
| 暗场噪声 | 荧光余辉 | 9.62 | 1.81 | 6.78 | 1.82 |

CPU 时间为各进程线程的合计，可能大于墙钟耗时。数据说明模拟绘制的开销，不代表整个程序或 USB 实机采集的同等降幅。OpenGL 的收益也包括 QGraphicsView 其他内容使用显卡绘制，不能仅视为曲线计算加速。

先画图再贴图不等于没有绘制成本。早期单色暗场对照中，Qt DeviceCoordinateCache 从约 4.66 ms 降到 3.95 ms，明显不如直接 OpenGL。变化的曲线仍需每帧重建图像；缓存更适合不变的背景、网格和文字。这不是对所有手写贴图实现的定论。

## 复现和验证

```sh
uv run python tools/benchmark_renderers.py raster
uv run python tools/benchmark_renderers.py opengl
uv run python tools/benchmark_renderers.py cached-image

# 需要真实桌面 OpenGL 上下文；不用光谱仪
uv run python tools/verify_gpu_rendering.py
SPECTRADESK_TEST_OPENGL=1 uv run pytest -q
```

基准和像素验证只使用模拟数据、临时配置，不连接光谱仪。
GPU 验证会读回专门的测试帧缓冲：逐波长比较彩虹颜色、确认填充面积、确认数据更新、检查余辉衰减、重复重画不增亮和坐标改变后清空历史。读回仅用于测试，正常显示不执行。

普通无桌面回归会跳过显卡测试；本机已执行包含显卡测试的完整 40 项回归（桌面 OpenGL 和 OpenGL ES 各有一项真实 GPU 回归）。GPU 像素检查不等于所有桌面合成器、DPI 或显示器组合都已验证；长时间实机采集和其他硬件仍需测试。Vulkan 未实现或测试。
