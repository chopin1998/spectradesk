# 峰面积

峰值分析表自动计算每个识别峰的面积，并显示起点、终点和峰面积；青色标记是起点，橙色标记是终点。面积结果和完整起止坐标会随测量保存，界面波长保留一位小数。

积分使用未平滑的校正光谱，以波长为横坐标做梯形积分，单位为 counts·nm。修改显示平滑不会改变面积。背景是峰显著度两侧参考点之间的直线，相邻峰之间的谷底不直接作为背景参考点。

起止点通过轻度平滑后的光谱寻找：从峰顶向外搜索，回落到峰高的 1% 或噪声估计的 3 倍（取较大者）时停止。平滑仅用于找边界。该区间不等同于数学上无限延伸的峰尾，噪声较大时会截去一部分尾部。

相邻峰没有回到背景时，以谷底分界并提示未作分峰拟合，面积不能解释成分离后各组分的真实积分。削顶峰提示面积仅为下限估计。分析范围截断或边界不可靠时显示提示，不给出完整面积；可以扩大分析范围后重试。

每一帧按当前识别到的峰重新计算，不需要勾选开关；没有识别到峰时清空结果和边界标记。

这些面积是相对计数面积，不是光功率、辐射能量或绝对荧光强度。宽带、多峰重叠、复杂倾斜背景的边界需结合实际光谱判断。
